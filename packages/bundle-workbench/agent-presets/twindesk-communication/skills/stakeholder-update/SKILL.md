# Stakeholder update

When drafting an update:

1. Lead with the user-visible impact and current confidence.
2. Keep unverified causes and dates explicitly conditional.
3. State the owner or next checkpoint when the source provides one.
4. Return draft text only; do not send it or imply approval.
